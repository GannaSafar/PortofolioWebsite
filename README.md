# Ganna Safar — Portfolio Website

Personal portfolio website for Ganna Safar, a Software Engineering graduate focused on frontend development, UI/UX, and practical web products.

**Live site:** [portofolio-website-beige-rho.vercel.app](https://portofolio-website-beige-rho.vercel.app)

## Highlights

- Responsive single-page portfolio built with Next.js and TypeScript
- Interactive skills and experience timeline
- Project case studies for PathFinder and ASU Learn
- Light/dark mode, sticky navigation, custom cursor, and accessible contact form
- Downloadable CV and direct links to GitHub, LinkedIn, and Figma work

## Tech stack

Next.js · React · TypeScript · CSS · Vercel

## Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
```
